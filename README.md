# 🚚 Delivery Logistics Backend

A **Spring Boot–based backend system** for managing customers, orders, deliveries, and agents in a logistics platform.  
Designed as a **clean monolith** with a **clear migration path to microservices**.

---

## 📌 Key Highlights

- Spring Boot **4.x**
- Java **21**
- PostgreSQL
- JWT-based **stateless authentication**
- Role-based authorization (**CUSTOMER, AGENT, ADMIN-ready**)
- Event-driven notification module
- Strict HTTP status code semantics (400 / 401 / 403 / 404 / 409)
- Clean layered architecture
- Production-grade exception handling
